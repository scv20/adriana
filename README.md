# Adriana — Podcast Companion for "Birth of a Parent"

After listening to an episode, you become the guest. Adriana (an ElevenLabs
voice agent) interviews you about the episode's themes. Prototype: Episode 5, Ritual.

Setup: paste your ElevenLabs agent id into `src/App.jsx` (AGENT_ID), enable
prompt + first-message overrides in the agent's Security tab, deploy on Netlify.
